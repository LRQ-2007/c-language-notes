## 📌 专升本C语言高频提醒
1. 链表必考：头插法、尾插法、遍历
2. 结构体 + 指针是大题核心
3. 注意 `malloc` 需要 `#include <stdlib.h>`，用完建议free释放内存
4. 头插法顺序和输入相反，尾插法顺序和输入一致
